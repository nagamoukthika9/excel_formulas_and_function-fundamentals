# Task 6: Excel Formulas and Functions Fundamentals

## Project Overview
This project was completed as part of my Data Analytics internship at Veda Technology. The objective was to practise essential Excel formulas and functions using the Sample Superstore dataset.

## Dataset
Sample Superstore sales data containing information about products, customers, regions, sales, quantities, discounts, and profits.

## Functions Practised
- **IF:** Categorised sales based on a specified condition.
- **SUMIFS:** Calculated sales based on criteria such as region.
- **COUNTIFS:** Counted records that met specified conditions.
- **VLOOKUP:** Retrieved sales information for a given product.
- **XLOOKUP:** Explored its functionality; the installed Excel version did not support it.
- **LEFT:** Extracted characters from the beginning of text.
- **RIGHT:** Extracted characters from the end of text.
- **LEN:** Counted characters in text.
- **UPPER:** Converted text to uppercase.
- **TRIM:** Removed unnecessary spaces from text.

## Key Learning Outcomes
- Practised applying Excel formulas to sales data.
- Learned to perform lookups and conditional calculations.
- Improved text cleaning and data manipulation skills.
- Gained practical experience with commonly used Excel functions.

## Tools Used
- Microsoft Excel
- Sample Superstore Dataset

## Conclusion
This task strengthened my understanding of Excel formulas and their practical applications in data analysis.
